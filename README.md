# Autonomous AI Newsletter Agent

An autonomous AI-powered newsletter generation system built using FastAPI, LangChain, Groq, and Tavily Search API.

The system automatically researches trending AI news, summarizes articles, analyzes industry trends, generates a professional newsletter, converts it into HTML format, and deploys it online using Render.

# Run Locally

## Clone Repository

```bash
git clone https://github.com/your-username/autonomous-ai-newsletter.git
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Start FastAPI Server

```bash
uvicorn app:app --reload
```

---

# Deployment

The project is deployed using Render.

Start Command:

```bash
uvicorn app:app --host 0.0.0.0 --port 10000
```
